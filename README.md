#  ProductBase — Product Manager

Full stack product management system built with Node.js, Express, MySQL and HTML/CSS/JS.

##  Features
-  JWT Authentication (Login/Signup)
-  Full CRUD for products
-  Image upload with Multer
-  Pagination
-  Search & Filter
-  Dashboard Stats
-  Dark professional UI

##  Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MySQL (XAMPP)
- **Auth:** JWT, Bcryptjs
- **Upload:** Multer
- **Frontend:** HTML, CSS, Vanilla JS

##  Run Locally
1. Clone the repo
2. Run `npm install`
3. Setup `.env` file with your DB credentials
4. Start XAMPP and run `node server.js`
5. Open `http://localhost:3001`
